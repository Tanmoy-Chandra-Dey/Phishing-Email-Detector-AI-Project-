# Phishing Email Detector (AI Project)

A beginner-friendly AI cybersecurity project that detects whether an email message is likely to be **phishing** or **legitimate** using machine learning.

## Features

- Trains a machine learning model on email text
- Predicts whether a new email is phishing or safe
- Shows prediction confidence
- Easy command-line interface
- Good starter portfolio project for cybersecurity + AI students

## Tech Stack

- Python 3
- pandas
- scikit-learn
